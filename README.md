# Proyecto Eventos

API REST para una plataforma de gestión de eventos.

## Tema del proyecto

El proyecto consiste en una plataforma donde los usuarios podrán consultar y registrarse a eventos. A futuro se incorporarán funcionalidades de autenticación, autorización, gestión de eventos e inscripciones.

## Tecnologías

- Node.js
- Express
- MongoDB
- Mongoose
- JavaScript
- ESM (ECMAScript Modules)
- dotenv
- bcrypt

## Instalación

Clonar el repositorio:

```bash
git clone https://github.com/PabloBalcar/proyecto-eventos.git
```
